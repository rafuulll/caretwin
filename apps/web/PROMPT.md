# PROMPT.md

Este projeto já é o app do CareTwin: o protótipo das telas de um acompanhamento gentil por pulseira, que compara cada dia com o normal da própria pessoa.

O roteiro que transformava um exemplo genérico em produto já foi aplicado aqui. Não existe exemplo a seguir nem entidade genérica a manter: o modelo de dados, as telas e os textos são os do CareTwin.

Quem for mexer neste código trata ele como produto. As regras estão no `AGENTS.md`, as decisões no `DECISOES.md` e o que falta ligar no `PROXIMOS-PASSOS.md`.
